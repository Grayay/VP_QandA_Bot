# Telegram FAQ бот

Простой Telegram-бот FAQ на Python, aiogram 3 и SQLite. FAQ импортируется из локального Excel-файла в базу данных.

## Что нужно подготовить

1. Python 3.11 или новее.
2. Telegram bot token от BotFather.
3. Excel-файл `Вопросы.xlsx` в корне проекта или `data/Вопросы.xlsx`.

В Excel-файле должны быть эти колонки:

- `Вопрос`
- `Ответ`
- `Отдел`
- `Раздел`

Бот читает FAQ из SQLite. Excel нужно импортировать перед запуском или после изменения таблицы:

```powershell
python scripts/import_faq_from_excel.py
```

Если файл отсутствует или обязательные колонки неверные, импорт завершится с ошибкой.

## Запуск на Windows PowerShell

Откройте PowerShell в папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В файле `.env` замените значение `BOT_TOKEN` на реальный токен бота.
В `BOOKER_IDS` укажите Telegram ID букеров через запятую. Пробелы и кавычки вокруг ID допустимы, например `BOOKER_IDS=123, 456,789`. Только эти пользователи увидят панель букера и смогут назначать дежурных.
В `CHIEF_BOOKER_IDS` укажите Telegram ID главных букеров, которые смогут управлять FAQ прямо в Telegram.
`DUTY_CUTOFF_HOUR` задаёт час, после которого вопросы по дежурным разделам откладываются на следующего дежурного букера. По умолчанию это `19`.
`APP_TIMEZONE` задаёт часовой пояс для этого правила. По умолчанию это `Europe/Moscow`.

Положите файл `Вопросы.xlsx` в корень проекта, импортируйте FAQ и запустите бота:

```powershell
python scripts/import_faq_from_excel.py
python main.py
```

Если PowerShell блокирует активацию виртуального окружения, выполните в этом же окне:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Команды дежурных букеров

- `/my_id` — показать ваш Telegram ID, чтобы добавить его в `BOOKER_IDS`.
- `/duty_castings` — назначить себя дежурным для раздела `Кастинги/букинги/съемки`.
- `/duty_income` — назначить себя дежурным для раздела `Дополнительный доход для моделей`.
- `/duty_status` — посмотреть текущих дежурных.

Эти команды доступны только пользователям из `BOOKER_IDS`.

Чтобы бот смог отправлять вопросы дежурному в личные сообщения, дежурный должен хотя бы один раз открыть бота и нажать `/start`.

Вопросы по дежурным разделам до `DUTY_CUTOFF_HOUR` отправляются текущему дежурному сразу. Вопросы в этот час и позже сохраняются как отложенные: бот отправит их букеру, который назначится дежурным на следующий день, либо текущему/последнему дежурному после следующего cutoff, если дежурный не сменился. Проверка отложенных вопросов запускается при старте бота, при назначении дежурного и далее периодически.

## Контакты

Плейсхолдеры для контактного сценария находятся в `config.py` в переменной `CONTACTS`. На первом экране отдельной кнопки контактов нет: пользователь увидит контактный или переводной сценарий внутри FAQ, если не удалось найти ответ.

## Данные

SQLite-база создаётся автоматически в файле `bot.sqlite3`.

Сохраняются:

- вопросы, на которые не получилось найти ответ;
- статус маршрутизации вопросов, получателя, время отправки и признак вопроса после cutoff;
- текущие дежурные букеры по двум специальным разделам;
- активные и удалённые через soft delete FAQ-вопросы.
